# 양방향 번역 — Lumiverse 확장

[Lumiverse](https://lumiverse.chat/)에서 응답과 내 메시지를 AI로 번역하는 양방향 번역 Spindle 확장입니다. Marinara Engine의 번역 기능을 참고해 만들었고, 아래 세 가지를 합쳤습니다.

- Marinara Engine의 기본 AI 번역: 응답 자동 번역, 내 메시지 번역, 번역문만 보기, 입력창 번역 버튼
- [번역 프리셋·단어장 1.5.4](https://github.com/minikkeuen/Marinara-Translation-Tools/releases/tag/1.5.4): 프리셋 전체, 채팅별 단어장, 기타 지침, 대사 지침, 이전 대화 참고
- **끊긴 번역 이어서 하기**와 긴 지문 나눠 번역 (번역 다듬기 0.2.3에서 착안, 코드는 새로 작성)

여기에 Lumiverse용 기능을 더했습니다: 번역하지 않을 부분(상태창 등) 지정, HTML 구조 보존, 번역문의 HTML 렌더링.

Lumiverse에는 기본 채팅 번역 기능이 없어서, 번역은 이 확장이 모두 맡습니다.

## 설치

1. Lumiverse → Extensions → **Add Extension** → *Install from Source*에 `https://github.com/mallang0723/LV-Translator` 입력 → **Install**
2. 확장을 켜고 권한 두 개를 허용합니다.
   - `generation`: 번역 모델 호출, 생성 종료 감지
   - `chat_mutation`: 메시지에 번역문 저장, 화면에 번역문 표시
3. 서랍(drawer)의 **번역** 탭, 또는 입력창 Extras 메뉴의 **번역 설정**에서 설정합니다.

## 사용법

연결 선택은 바로 저장되고, 나머지 설정은 **저장** 버튼을 눌러야 적용됩니다. 저장하지 않은 변경이 있으면 저장 줄이 강조되고 "저장하지 않은 변경이 있어요"가 표시되며, 번역을 시작하거나 페이지를 떠날 때 한 번 더 물어봅니다.

설정은 **채팅마다** 저장됩니다. 채팅이 열려 있지 않을 때 저장하거나 **저장 + 새 채팅 기본값으로**를 누르면, 아직 설정이 없는 채팅의 기본값이 됩니다. 프리셋은 모든 채팅이 함께 씁니다.

### 기본 번역 (Marinara 채팅 번역 설정과 같음)

| 설정 | 설명 |
|---|---|
| 번역에 쓸 AI 연결 | Lumiverse 연결 중 하나. **고르는 즉시 저장됩니다.** 고르지 않으면(자동) 채팅에 지정된 연결 → 지금 쓰는 연결 → 기본 연결 → 첫 연결 순으로 씁니다. 고른 연결이 삭제되면 같은 순서로 대신 쓰고 알려 줍니다 |
| 모델 언어 / 내 언어 | 내 메시지는 모델 언어로, 응답은 내 언어로 번역 |
| AI 응답 자동 번역 | 응답 생성이 끝나면 저장된 최종 응답을 번역. 브라우저를 닫아도 서버에서 동작 |
| 번역이 끊기면 자동으로 이어서 번역 | 모델이 출력 한도로 멈추면 그 자리부터 이어서 번역(최대 4회) |
| 번역문 표시 방식 | 원문 아래에 번역문 / **번역문 먼저(번역문 아래에 원문)** / 번역문만 / 원문 + 접힌 번역문 / **문단 대조** (아래 참고) |
| 번역 단위 | 메시지 통째로(1회 요청) / 문단별(문단마다 1회 요청) |
| 내 메시지를 보내기 전에 번역 | 보내기 직전에 번역해 **번역문을 채팅에 저장**(Marinara와 같음). 실패하면 원문을 보내고 알림 |
| 입력창 옆에 번역 버튼 표시 | 입력 중인 글을 모델 언어로 번역해 입력창에 넣음. 그대로 보내도 다시 번역하지 않음 |

### 메시지별 버튼

각 메시지의 **동작 줄**(수정·복사·숨김·앵커·분기·삭제 아이콘이 있는 줄) 끝에 아이콘 두 개가 붙습니다.

- **번역(文A):** 번역합니다. 이미 번역이 있으면 "다시 번역"으로 새로 번역합니다. 번역 중에는 깜박이며 누르면 중단합니다.
- **번역 삭제(文A에 ×):** 지금 보이는 스와이프의 번역문만 지웁니다(확인을 한 번 묻습니다). 그 스와이프에 번역이 있을 때만 보이고, 다른 스와이프의 번역과 메시지는 그대로입니다. 스와이프를 넘기면 버튼이 따라 바뀝니다. 호스트의 휴지통(메시지 삭제)과 다른 아이콘입니다.

버튼 크기·색·호버는 호스트 동작 줄과 같습니다(휴대폰에서도 호스트 아이콘과 같은 크기라 44px보다 작습니다).

메시지 아래 작은 줄은 번역 중 진행·취소, 오류, "번역이 중간에 끊겼습니다 (2/5)"와 **이어서 번역**, **번역 보기/숨기기**가 있을 때만 나타납니다. 문단 대조에서는 번역 보기/숨기기가 없고, 번역 중·오류·중간에 끊김일 때만 나타납니다. **이어서 번역**은 끊긴 곳부터 이어 갑니다.

번역문은 원문 내용별로 저장되므로 스와이프마다 따로 남고, 원문을 고치면 새로 번역할 대상이 됩니다.

### 문단 대조 (Paragraph Reader)

표시 방식을 **문단 대조**로 고르면 Paragraph Reader 0.2.0처럼 원문 N과 번역 N을 문단별로 짝지어 보여 줍니다. 메시지에는 번역 내용이 나오고, 번역·다시 번역·번역 삭제는 메시지 동작 줄 버튼으로 합니다. 서랍의 **문단 대조** 구역에는 모든 메시지에 적용되는 설정만 있습니다(표시 방식을 고르면 바로 나타납니다).

- **보기:** 원문·번역 교차 / 눌러서 원문(번역만 보이고, 문단마다 눌러서 원문을 펼침). 바로 저장됩니다.
- **문단 안 순서:** 교차 보기에서 문단마다 원문 → 번역 또는 번역 → 원문 중 고릅니다. 모든 채팅에 적용되고 바로 저장됩니다. "눌러서 원문"은 번역이 항상 위라 순서 설정이 없습니다.
- **도착 언어:** "내 언어"와 같은 설정입니다. 저장 버튼으로 저장합니다.
- **글자 크기:** 원문·번역을 따로 12~32px로 조절합니다. 모든 채팅에 적용되고 바로 저장됩니다. 보기 전환과 크기 변경은 다시 번역하지 않습니다.
- **번역 단위가 "문단별"이면** 문단마다 따로 요청해 정확히 짝이 맞습니다. 중간에 멈추면 "이어서 번역"으로 남은 문단만 번역합니다.
- **"메시지 통째로"이면** 1회 요청으로 번역한 뒤, 원문과 번역의 문단 수가 같으면 순서대로 짝짓고, 다르면 "원문 전체 / 번역 전체"로 보여 줍니다.
- 글자·숫자가 없는 문단(`* * *`, `---`, 태그만 있는 줄)과 코드 블록, 번역하지 않을 부분은 요청하지 않고 한 번만 표시합니다.
- 여는 태그와 닫는 태그가 다른 문단에 있는 HTML은 한 덩어리로 묶어 보여 줍니다.
- 원문과 번역문 모두 Lumiverse가 메시지를 그리는 방식(마크다운·HTML)으로 그려집니다.

### 프롬프트 프리셋

- 1.5.4의 기본 프리셋을 **모두** 넣었습니다. 기존판, v2, 의역, 영문학 번역체, 인풋용, 대사 병기를 1.5.4와 같은 순서로 보여 줍니다.
- 응답(Incoming)과 내 메시지(Outgoing) 방향마다 따로 고릅니다.
- **채팅 설정 유지**를 고르면 그 채팅의 프롬프트를 씁니다. 비워 두면 Marinara 기본 프롬프트를 씁니다.
- 내 프리셋을 만들고 수정·삭제할 수 있습니다. 기본 프리셋은 읽기 전용이고, 복사해서 새로 만들 수 있습니다.
- 프롬프트의 `{{targetLanguage}}`는 대상 언어로 바뀝니다.

### 단어장 · 참고 정보 (1.5.4와 같음)

- **단어장:** 한 줄에 `내 언어 용어 = 모델 언어 용어`. 양방향으로 적용되며, 원문에 나온 쪽을 보고 방향을 정합니다.
- **기타 지침:** 장르·시대·지역·배경 등. 용어 선택에만 쓰고 내용은 더하지 않도록 지시합니다.
- **대사 지침:** 응답 번역에만 `# Character Voice Instructions`로 붙습니다.
- **이전 대화 참고:** 최근 1~10개 메시지의 원문과 번역문을 참고로만 넣습니다. 기본은 응답 번역에만 넣고, 옵션을 켜면 내 메시지 번역에도 넣습니다. 숨긴 메시지는 넣지 않습니다.
- 시스템 프롬프트가 5,000자, 본문이 50,000자를 넘으면 **자르지 않고 번역을 멈추고** 알려 줍니다.

### 번역하지 않을 부분

- **HTML:** 태그와 속성(`<div class="…">` 등), `<style>`·`<script>` 내용, 주석은 그대로 두고 태그 사이 글자만 번역합니다.
- **코드 블록:** ` ``` ` 안은 번역하지 않습니다.
- **`{{매크로}}`:** 항상 그대로 둡니다.
- **제외할 HTML 태그:** `choices, status` 처럼 태그 이름을 쉼표·공백으로 적으면, 그 태그의 요소 전체(여는 태그부터 닫는 태그까지, 안쪽 내용 포함)를 번역에 보내지 않고 그대로 되돌립니다. 같은 이름이 중첩돼도 짝을 맞춰 찾고, 닫히지 않은 요소는 글 끝까지 보호합니다. 코드 블록과 주석 안의 태그는 무시하고, `<br>` 같은 빈 태그와 `<x/>` 형태는 범위로 잡지 않습니다. `strong`·`em` 은 안쪽 글자를 계속 번역합니다(태그만 유지). **추천 태그 넣기** 버튼이 `choices, options, status, stats` 를 더합니다. 기본값은 비어 있습니다.
- **`<style>`·`<script>`:** 위 HTML 설정을 꺼도 항상 그대로 둡니다.
- **제외 규칙:** 한 줄에 하나씩 적습니다.

  ```text
  <status>                  ← <status ...>...</status> 요소 전체
  /HP: \d+\/\d+/            ← 정규식과 일치하는 부분
  [상태창] ... [/상태창]     ← 시작부터 끝까지 (" ... " 로 구분)
  ```

보호한 부분은 번역 전에 `⟦1⟧` 같은 표시로 바뀌어 모델에 원문이 가지 않고, 번역 후 원래대로 돌아옵니다. 원문에 `⟦1⟧` 이 이미 있어도 우리 표시와 섞이지 않게 먼저 따로 보관합니다(그래서 번호 외에 별도의 무작위 값은 쓰지 않습니다). 모델이 표시를 빠뜨리거나 늘리면 한 번 다시 번역하고, 그래도 어긋나면 **표시 사이의 글을 하나씩 따로 번역해 표시를 우리가 다시 끼워 넣습니다**(요청이 늘어나므로 조각이 40개를 넘으면 하지 않습니다). 그것도 안 되면 HTML이 깨지지 않도록 그 부분을 저장하지 않고 오류로 알립니다.

### 번역문의 HTML

번역문은 Lumiverse가 메시지를 그리는 방식(마크다운, HTML)으로 그대로 그려집니다. 원문의 카드·상태창 HTML이 번역문에서도 똑같이 보입니다. 저장된 원문은 바뀌지 않고, AI에게 가는 대화 기록에도 원문이 들어갑니다.

### 긴 지문

설정한 글자 수(기본 7,000자) 이상이면 문단 단위로 약 3,200자씩 나눠 차례로 번역합니다. 조각이 끝날 때마다 저장되므로 중간에 실패해도 **이어서 번역**으로 남은 조각부터 계속합니다.

## Marinara · 1.5.4와 다른 점

- 번역 제공자는 AI 연결만 지원합니다(Google·DeepL·DeepLX 없음).
- 1.5.4의 "후처리 후 번역" 옵션은 없습니다. 항상 생성이 끝나고 저장된 최종 응답을 번역합니다.
- 1.5.4에서 "채팅 설정 유지" + 빈 채팅 프롬프트 + 대사 지침을 켜면 번역 지시문 없이 대사 지침만 보내지는데, 여기서는 Marinara 기본 프롬프트를 앞에 유지합니다. 나머지 요청 형식은 1.5.4와 같습니다(테스트로 확인).
- 내 메시지 번역은 입력창이 메시지를 만드는 요청(`POST /api/v1/chats/:id/messages`)을 브라우저에서 가로채 번역합니다. Lumiverse가 이 요청 방식을 바꾸면 동작하지 않을 수 있습니다. 멀티플레이 방에서 보내는 메시지는 번역하지 않습니다.
- 입력창 번역 버튼은 Lumiverse 입력창(`textarea[name="chat-message"]`)을 직접 다룹니다.
- 메시지 동작 줄 버튼: 말풍선(bubble) 배치에서는 Lumiverse의 `message_actions` 장착 지점(`ctx.ui.registerDomDecorator`)을 씁니다. 기본인 미니멀 배치에는 그 지점이 없어서 `message_footer` 지점 옆의 동작 줄을 찾아 직접 붙입니다(`MutationObserver`, 중복 방지, 종료 시 제거). Lumiverse가 동작 줄 구조를 바꾸면 버튼이 안 보일 수 있고, 그 경우 메시지 아래 줄과 자동 번역은 그대로 동작합니다.
- 표시 방식을 위해 Lumiverse의 메시지 표시 처리기(render)를 등록하므로, 스트리밍 중 글자가 화면에 그려지는 방식이 조금 달라질 수 있습니다.

## 검증 기록

- **자동 테스트(`bun test`) 123개**
  - 프리셋 원문·메타데이터가 1.5.4의 SHA-256 기준값과 일치
  - 1.5.4 원본 코드를 vm에서 실행해 기록한 24가지 번역 요청과 글자 단위로 일치(위의 의도적 차이 1건 제외)
  - 보호·복원, 제외 규칙, 긴 지문 나누기, 이어 붙이기
  - 엔진: 자동·수동 이어서 번역, 실패 후 재개, 표시 누락 재시도, 취소
  - 문단 대조: 문단 나누기, 요청 없이 둘 문단, HTML 묶기, 짝 맞추기, 화면 HTML
  - 번역·다시 번역·번역 삭제 버튼 상태, 번역 삭제와 다시 번역 판단(0.1.2)

## 0.2.0

RP 번역표시 설정 확장 1.0.2(아래 "참고" 절)를 참고해 Lumiverse용으로 구현했습니다.

- **표시 방식 "번역문 먼저"**를 더했습니다. 번역문 아래에 원문이 붙습니다.
- **문단 대조의 문단 안 순서**를 고를 수 있습니다(원문 → 번역 / 번역 → 원문).
- **제외할 HTML 태그 목록**을 더했습니다. 요소 전체를 번역에 보내지 않고 그대로 복원합니다. `<style>`·`<script>` 는 HTML 보호를 꺼도 항상 그대로 둡니다.
- **표시를 모델이 망가뜨렸을 때**, 이전에는 두 번째 실패에서 오류로 끝났습니다. 이제 표시 사이의 글을 하나씩 번역해 이어 붙이는 대체 경로를 먼저 시도합니다.
- 원문에 `⟦1⟧` 같은 글자가 이미 여러 개 있을 때 복원이 어긋나던 버그를 고쳤습니다.
- 표시 방식 대응(참고 확장 → 이 확장):

  | 참고 확장 | 이 확장 |
  |---|---|
  | 번역만 표시 | 번역문만 (기존) |
  | 번역 우선 표시(원문은 접어 둠) | 문단 대조 → 눌러서 원문 (기존) |
  | 원문 우선 표시(번역은 접어 둠) | 원문 + 접힌 번역문 (기존, 메시지 단위) |
  | 번역–원문 함께 보기 | 문단 대조 → 교차, 문단 안 순서 "번역 → 원문" (신규) |
  | 원문–번역 함께 보기 | 문단 대조 → 교차, "원문 → 번역" (기존) |
  | (없음) | 번역문 먼저 / 원문 아래에 번역문 (메시지 단위, 앞의 것이 신규) |

- **설정 위치는 서랍의 번역 탭에 두었습니다.** 참고 확장은 메시지 동작 줄에서 여는 설정창을 쓰지만, 이 확장은 0.1.2에서 동작 줄에 번역·번역 삭제 두 아이콘만 두고 설정은 서랍으로 모았습니다. 호스트 아이콘 크기에 맞춘 줄(휴대폰에서도 44px보다 작음)에 설정 아이콘을 하나 더 얹으면 오터치가 늘고, 표시 방식과 제외 태그는 메시지가 아니라 채팅 단위 설정이라 메시지마다 버튼을 둘 이유도 없습니다. 서랍 패널은 이미 Lumiverse 테마 변수(`--lumiverse-*`)를 써서 밝은 테마·어두운 테마를 그대로 따라갑니다.
- 저장된 번역 데이터 형식은 그대로입니다. 새 설정(`excludeTags`, 문단 안 순서)은 없으면 기본값을 씁니다. 새 권한은 없습니다.

## 0.1.4

- **문단 대조에서 번역 보기/숨기기 버튼을 없앴습니다.** 문단 대조는 원문이 번역과 함께 보이므로 숨길 이유가 없습니다. 번역을 없애려면 메시지 동작 줄의 번역 삭제(文A×) 버튼을 쓰세요. 문단 대조에서 메시지 아래 작은 줄은 번역 중, 오류, 중간에 끊겨 이어서 번역할 때만 나타나고, 정상으로 번역된 메시지에는 나타나지 않습니다.
- 다른 표시 방식에서 숨겨 둔 메시지도 문단 대조에서는 번역이 보입니다. 숨김 표시는 지워지지 않으므로, 다른 표시 방식으로 돌아가면 번역 보기 버튼으로 다시 켤 수 있습니다.
- 다른 표시 방식(원문 아래, 번역문만, 접힌 번역문)은 그대로입니다.
- 저장된 번역 데이터 형식은 0.1.3과 같습니다.

## 0.1.3

- **번역 삭제는 지금 보이는 스와이프의 번역만 지웁니다.** 이전에는 메시지의 모든 스와이프 번역이 한꺼번에 지워졌습니다. 메시지 동작 줄의 번역 삭제 버튼에 적용됩니다.
- **서랍의 "선택한 메시지" / "메시지 번역" 구역을 없앴습니다**(문단 대조 포함). "대상 메시지: #N", 상태 문구, 새로 번역·이어서 번역·번역 숨기기·이 메시지 저장 삭제 버튼이 빠졌습니다. 메시지마다 자기 버튼이 있어 겹쳤기 때문입니다. 서랍에는 보기·도착 언어·글자 크기 같은 전체 설정만 남습니다. 오류·끊김·이어서 번역·번역 보기/숨기기는 메시지 아래 작은 줄이 맡고, 이 줄은 이제 문단 대조에서도 나타납니다.
- 번역 삭제 버튼은 지금 보이는 스와이프에 번역이 있을 때만 나타나고, 스와이프를 넘기면 따라 바뀝니다.
- 삭제 확인을 누른 뒤 스와이프를 넘기면 확인이 취소됩니다. 사용자가 본 스와이프의 번역만 지워지고, 그 사이 바뀐 스와이프는 건드리지 않습니다.
- 저장된 번역 데이터 형식은 0.1.1·0.1.2와 같습니다. 번역은 원래 스와이프(본문)마다 따로 저장돼 있었습니다. 본문이 완전히 같은 스와이프끼리는 번역을 공유하므로 함께 지워집니다.
